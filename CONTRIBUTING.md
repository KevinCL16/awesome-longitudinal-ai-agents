# Contributing

This list tracks research on agents and Human–AI systems in which work done now can alter how cognition, behavior, coordination, or capability unfolds later.

## What belongs here

Submit a paper, benchmark, survey, or clearly labeled engineering/research report when it makes a concrete contribution to at least one of the following:

- reusing experience, trajectories, feedback, workflows, rules, or skills across tasks;
- continual, lifelong, or self-evolving agents;
- adaptive allocation of reasoning, verification, routing, stopping, revision, or context;
- repeated Human–AI adaptation, including shared autonomy, deferral, personalization, feedback, reliance, skill formation, or deskilling;
- foundational work needed to understand these mechanisms.

Do not add generic agent, memory, prompting, or automation work merely because it mentions persistence or context. The entry should state how earlier work changes later conduct.

## Entry requirements

- Use the canonical title, author list, year, venue, and stable official URL. Prefer official proceedings, publisher pages, or DOI resolvers; use arXiv when no formal record is available.
- Add one restrained sentence describing the actual mechanism or empirical contribution.
- Put the item in one primary section. Cross-links are fine only when necessary.
- Mark company material as **Engineering / deployment report**, **Research report**, or **Policy / perspective**; do not present it as peer-reviewed evidence.
- Do not add citations you have not verified from an official source.

## Pull requests

Keep each PR narrow: one contribution type, coherent metadata cleanup, or one taxonomy adjustment. Explain why the item is longitudinal rather than merely adjacent. Do not alter the manuscript corpus or silently replace canonical records.
